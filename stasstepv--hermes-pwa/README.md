# hermes-pwa

> Source: [stasstepv/hermes-pwa](https://github.com/stasstepv/hermes-pwa) — distributed by [TomeVault](https://tomevault.io)

Unofficial mobile PWA for Hermes Agent — installs as a plugin in your Hermes Dashboard (web UI) and adds a Mobile tab. Chat, approve actions, and watch your agent from your phone.
