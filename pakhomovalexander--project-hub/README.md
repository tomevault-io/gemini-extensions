# project-hub

> Tome by [PakhomovAlexander](https://github.com/PakhomovAlexander/project-hub) — distributed by [TomeVault](https://tomevault.io)

A template for running a project with Claude Code as a 'cockpit' repo: ubiquitous-language glossary, invariants, ADRs, a living tracker, repo linking, and a prompt-before-risky-commands hook. Point Claude at it and say 'set up a hub for X'.
