# farbwerk

> Source: [Umami-Creative-GmbH/farbwerk](https://github.com/Umami-Creative-GmbH/farbwerk). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Farbwerk takes a base color, builds the eleven Tailwind steps, lets you add a secondary and tertiary scale linked by a harmony rule, scores every contrast pair with APCA and WCAG 2, and repaints a gallery of real components so you can see the palette doing its job before you export it.
