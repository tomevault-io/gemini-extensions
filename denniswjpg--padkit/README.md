# padkit

> Tome by [denniswjpg](https://github.com/denniswjpg/padkit), graded and kept true across every major AI platform by [TomeVault](https://tomevault.io)

Open-source firmware + tooling to turn a cheap 6-key + rotary-knob CH552 macropad into a fully programmable controller: flash it, bind keys anywhere, configure LEDs/keymap from your browser (WebHID), or integrate via a Go daemon + MCP.

## Gemini CLI Config

The `GEMINI.md` file in this directory is the project config converted for Gemini CLI.
Original source: `AGENTS.md` in [denniswjpg/padkit](https://github.com/denniswjpg/padkit).
