# PortPS5

> Source: [yuriolive/PortPS5](https://github.com/yuriolive/PortPS5). Graded, signed and kept current as the models change by [TomeVault](https://tomevault.io)

Converts decrypted PS5 game dumps into native Windows executables via binary relinking, replacement system libraries, and Vulkan. No CPU emulation.

## Gemini CLI Config

The `GEMINI.md` file in this directory is the project config converted for Gemini CLI.
Original source: `AGENTS.md` in [yuriolive/PortPS5](https://github.com/yuriolive/PortPS5).
